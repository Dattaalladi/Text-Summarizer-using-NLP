# 🧠 Text Summarizer using NLP

An NLP-based application that generates concise summaries from lengthy text inputs using both extractive and abstractive summarization techniques. Ideal for processing articles, reports, documents, or any long-form content.

## 🚀 Features

- 🔍 **Extractive Summarization** – Selects key sentences based on ranking algorithms.
- 🧠 **Abstractive Summarization** – Generates new sentences that capture the essence of the input text.
- 🗣️ **Natural Language Processing** – Powered by libraries like NLTK, spaCy, or Hugging Face Transformers.
- 🌐 **User Interface (Optional)** – Simple and intuitive frontend for ease of use.
- 📁 Accepts plain text or text files as input.
- 📊 Clean output with summary length control.
